# Disk Meter title icon

The user selected [Lucide hard-drive](https://lucide.dev/icons/hard-drive) as an SVG data URL on 2026-09-12. `hard-drive.svg` preserves the exact decoded bytes, including the original 24-unit canvas and four paths.

Lucide uses the [ISC license](https://lucide.dev/license). The full upstream license, including the Feather notices for other listed icons, is retained in `LICENSE`. It matches the suite's existing upstream license from [Lucide revision a79b2d131dab2bf20cb224bd0937b439a9c4fa99](https://github.com/lucide-icons/lucide/tree/a79b2d131dab2bf20cb224bd0937b439a9c4fa99), and was reviewed against Lucide's license page for this change.

`View.inc` adapts the supplied SVG into native Rainmeter Shape paths: coordinates/radii and the two-unit stroke scale by `TitleIconSize / 24`; currentColor maps to MutedColor. Round caps/joins and the original two short indicator strokes are preserved. SVG sweep0 maps to Rainmeter sweep1. The icon is centered on TitleRowCenterY and scales with TitleFontSize. The SVG is retained for provenance, not loaded at runtime. No plugin, font, raster asset, or runtime download is added.
